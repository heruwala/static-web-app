# Under Construction Landing Site

A React single-page experience that presents an expressive under-construction message with animated telemetry, milestone cards, and responsive layout.

## Run Locally

1. Install dependencies:

```bash
npm install
```

2. Start development server:

```bash
npm start
```

3. Open http://localhost:3000

## Quality Checks

Run tests:

```bash
npm test
```

Create production build:

```bash
npm run build
```

## Notes

- The app currently uses Create React App tooling.
- Some package majors remain pinned for compatibility with the current CRA stack.
